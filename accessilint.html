AccessiLint

Accessibility issues are easiest to fix when you catch them the moment they're introduced — not during QA, not in a post-launch audit. AccessiLint is a Visual Studio extension that brings WCAG 2.1 AA checking directly into your editor, so violations surface as warnings right alongside your code.

What It Does

AccessiLint statically analyzes HTML, Razor, CSHTML, and CSS files as you work. It covers all four WCAG POUR principles — Perceivable, Operable, Understandable, and Robust — across 54 rules, each one traceable back to official W3C technique documentation. Violations appear in the Error List with rule codes and plain-English descriptions so you always know what to fix and why.

Who It's For

If you're building ASP.NET MVC apps, Razor Pages sites, or Blazor components in Visual Studio 2022 or later, AccessiLint works with your existing workflow. No extra tools, no separate audit step — just warnings that keep accessibility visible at every stage of development.

What It Catches

  • Missing or empty alt attributes on images and image maps
  • Color contrast failures and text sizing that ignores user preferences
  • Mouse-only event handlers with no keyboard equivalent
  • Forms missing submit buttons or using auto-submitting onchange handlers
  • Invalid or incomplete ARIA usage and landmark structure
  • Data tables missing headers, captions, or proper associations
  • Inaccessible <iframe> elements, page titles, and more

Built to Last

AccessiLint is written in C# on .NET, using HtmlAgilityPack for HTML parsing and a purpose-built CSS parser that handles inline styles, style blocks, and linked stylesheets. Every rule is backed by xUnit tests — 484 passing at release — so you can trust that what it flags is real.

Getting Started

AccessiLint 1.0 is available on the Visual Studio Marketplace from NovaWright Studios.

  1. Open Visual Studio 2022 or later
  2. Go to Extensions → Manage Extensions
  3. Search for AccessiLint
  4. Install and restart — analysis begins automatically

What's Coming

Version 1.0 covers the full WCAG 2.1 AA ruleset. Next on the roadmap is AccessiLint Audit Reports — a Visual Studio command that scans an entire solution and produces a professional accessibility report in Word format, suitable for clients and compliance teams. This will be available as a separate paid product. Expanded WCAG 2.2 coverage and additional file type support are also planned.
