NovaWright Folder Watch In Development

Windows Desktop Utility

Know what changed in your folders, when it happened, and where it happened.

NovaWright Folder Watch is a Windows utility that monitors folders and their subdirectories, recording file and folder activity as it occurs. Whether you're keeping an eye on development projects, shared network folders, backups, or important documents, Folder Watch gives you a convenient way to track changes without manually checking each location.

Monitor multiple folders from one window and see when files or folders are created, modified, deleted, or renamed. Each activity entry includes a timestamp and the affected path, so you can quickly identify what changed and where to look.

Key Features

  • Monitor Multiple Folders — Select multiple folders across available drives, including mapped network drives
  • Track File and Folder Activity — Record creations, modifications, deletions, and renames
  • Monitor Subdirectories — Keep track of activity throughout the selected folder trees
  • Detailed Activity History — Review timestamps, actions, file names, folder names, and full paths
  • Persistent History — Retain recorded activity between application sessions
  • Configurable Monitoring — Start and stop monitoring when you need it
  • Remember Watched Folders — Restore your saved folder selections when the application starts
  • Manage Selections Easily — Add folders, remove multiple selections, or clear the watched-folder list

A Practical Windows Utility

Instead of repeatedly checking directories yourself, you can monitor the locations that matter and review a centralized history of their changes. Folder Watch is currently in development by NovaWright Studios.
