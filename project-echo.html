Project Echo In Development

Action / Stealth Game — PC

Project Echo is a sci-fi stealth action game in development at NovaWright Studios. In Echo, sound is at the center of everything — the way you move, the way enemies detect you, and the way you can use the environment to your advantage.

Navigate through tense, atmospheric environments where every footstep matters. Stay quiet to remain hidden, or use sound strategically to redirect threats and create opportunities. The world reacts to what it hears.

Planned Features

  • Sound-based detection system that drives enemy AI behavior
  • Stealth and action playstyle options with different risk/reward tradeoffs
  • Atmospheric sci-fi environments across multiple locations
  • Gear and abilities that interact with sound mechanics
  • Story-driven campaign with multiple paths through each mission

Development Status

Project Echo is in early development. The core design and mechanics are being established before moving into full production. More details — including screenshots, video, and a release window — will be shared here as the project takes shape.

In early development. Project Echo does not have a release date yet. Follow NovaWright Studios for updates as development progresses.
