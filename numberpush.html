Number Push

Number Push is a puzzle game about pushing crates onto goals.

THE GOAL

Move your player to push every crate onto a goal square. When all crates are on goals, the level is complete.

THE NUMBER ON EACH CRATE

Each crate has a number - that is its distance. When you push a crate, it slides exactly that many squares in the direction you pushed it. A crate with a 3 moves 3 squares. If anything blocks the path before it travels its full distance, the push is not allowed.

GOALS

Goal squares are marked on the board. A crate lands on a goal only if its distance carries it exactly onto one. Every goal must be covered to complete the level.

KEYBOARD CONTROLS

Arrow keys or WASD - move the player. R - reset the level

CONTROLLER CONTROLS

AccessiLint 1.0 is available on the Visual Studio Marketplace from NovaWright Studios.

  1. D-Pad or Left Stick - move the player
  2. Y - reset the level
  3. B - go back
  4. Start - options menu
  5. Right Trigger - open solution viewer
  6. Left Trigger - toggle crate numbers
  7. On the level select screen:
  8. D-Pad Up / Down - navigate the level list
  9. A - start the selected level
  10. Start - options menu
  11. Left Stick Click - How to Play / Scroll
  12. Right Stick Click - Instructions / Scroll

SOLUTION VIEWER (CONTROLLER)

  1. Up / Down - navigate between buttons
  2. A - activate the focused button
  3. B - go back / close
  4. In Step by Step mode:
  5. Left / Right - previous / next step
  6. B - back to choice screen
  7. Start - close

OPTIONS MENU (CONTROLLER)

  1. Up / Down - move between volume sliders and button row
  2. Left / Right - adjust volume or cycle between buttons
  3. A - jump to button row / activate selected button
  4. B or Start - cancel and close

TIPS

  1. - Turn on Show Crate Numbers (or Left Trigger) to follow the solution
  2. - The Solution button gives you a hint - step by step if you prefer
  3. - The MINIMUM shows the fewest pushes possible. Can you match it?
